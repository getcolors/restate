Restate Package Skill

A reproducible Green workflow for one durable Restate server and TypeScript reference application on DigitalOcean.

Boundary

Cloudflare and Caddy expose HTTPS only. Restate ingress, administration, fabric and SDK ports remain private. The configured Amsterdam region's default VPC is discovered at runtime and is never created or hard-coded.

Recovery

Persistent state survives service and Droplet restarts. Daily consistent R2 backups support manual disaster recovery; this single-node design does not provide high availability.
